# PR Assistant — prototype Android

## Fonctionnalités
- Mini-panneau rectangulaire flottant et déplaçable.
- Compteur manuel des tâches validées.
- Chronomètre de session.
- Pause de 5 minutes.
- Rappel avec délai variable (25 à 55 secondes) pour organiser le rythme de travail.

## Limites volontaires
Ce prototype ne se connecte pas à PR.SOCIAL, ne lit pas les pages, ne clique pas sur Instagram/Follow, ne simule pas une personne et ne contourne pas les restrictions Instagram. Le bouton « +1 tâche » sert à enregistrer une tâche que l'utilisateur a lui-même terminée.

## Ouvrir le projet
1. Installer Android Studio.
2. Ouvrir le dossier `PR_Assistant_Android`.
3. Laisser Gradle synchroniser le projet.
4. Lancer sur un téléphone Android (Android 8.0 ou plus récent).
5. Ouvrir PR Assistant, autoriser « Affichage par-dessus les autres applis », puis afficher le mini-écran.

Le projet est un prototype source, pas encore un APK signé.
